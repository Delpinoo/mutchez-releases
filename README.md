# MutchEz — Releases

Instaladores oficiales de **MutchEz** para Windows. Acepta o rechaza tus partidas de League of Legends desde el celular escaneando un código QR.

Official **MutchEz** installers for Windows. Accept or decline your League of Legends matches from your phone by scanning a QR code.

## Descargar / Download

👉 [Última versión / Latest release](https://github.com/Delpinoo/mutchez-releases/releases/latest)

- El celular debe estar en la misma Wi-Fi que el PC / Your phone must be on the same Wi-Fi as your PC

## ¿Windows muestra un aviso? / Windows shows a warning?

El instalador aún no está firmado con un certificado de pago, así que SmartScreen puede mostrar "Windows protegió tu PC". Haz clic en **Más información** → **Ejecutar de todas formas**. Cada release incluye el hash SHA-256 para que verifiques el archivo.

The installer is not yet signed with a paid certificate, so SmartScreen may show "Windows protected your PC". Click **More info** → **Run anyway**. Each release lists the SHA-256 hash so you can verify the file.
